How it works

  1. Take your set, A, B, C or D. This page picks one for you at random and remembers it in this browser. Stay with it.
  2. Pick a group you know. Every set has every group.
  3. Open a batch. Up to 30 records in one Identify page. Identify hides records that reached Research Grade since the list was built, so a batch can run short.
  4. ID what you can, skip the rest. Add an ID, agree, or mark reviewed, as always.
  5. Tick it done and note the code, e.g. A-016.
